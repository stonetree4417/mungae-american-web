# 멍개미국어 · 孟狗美语

> 영어 아니고 미국어

기본 문법은 학교에서 이미 배웠습니다. 실전에서 갈리는 건 패턴입니다.
패턴 + 어휘, 이 둘이 미국인과 자유롭게 대화하는 힘입니다.

**도착지 두 곳** — 미국인과 자유롭게 대화 / 미국 영화를 자막 없이
**트랙 둘** — 패턴 300 (입) · 어휘 5,000 (귀)

---

## 지금 상태

| 항목 | 값 |
|---|---|
| 마스터 인덱스 | 패턴 300개 (레벨별 100개) |
| 예문 수록 | 60개 (300문장) |
| 남은 작업 | 예문 미작성 240개 |
| 앱 버전 | `version.properties` 참조 |

## 폴더 구조

```
├─ index.html                 ← 빌드 결과물. 손으로 고치지 마십시오
├─ template.html              ← 화면과 로직. 기능을 바꿀 때 여기
├─ build.py                   ← JSON을 template에 주입해 index.html 생성
├─ version.properties         ← 앱 버전 단일 소스
├─ CHANGELOG.md               ← 변경 이력. 릴리즈 노트의 단일 소스
├─ data/
│  ├─ patterns.json           ← 수록 콘텐츠 (예문 포함). 콘텐츠 작업은 여기
│  └─ patterns-index.json     ← 패턴 300 마스터 목록. 새 패턴은 반드시 여기 먼저
├─ .github/workflows/
│  └─ build-web.yml           ← data를 고치면 index.html 자동 재빌드
└─ docs/                      ← 안드로이드 릴리즈 키트, 네이밍·ASO 전략
```

## 콘텐츠를 추가하는 법

터미널 없이 GitHub 웹에서 끝납니다.

1. `data/patterns-index.json`에서 추가할 패턴이 목록에 있는지 확인합니다. 없으면 먼저 넣습니다.
2. `data/patterns.json`의 `patterns` 배열에 항목을 추가합니다. 예문은 **5개**이며, 마지막 하나는 검정 전용으로 봉인됩니다.
3. 커밋하면 `build-web.yml`이 돌아 `index.html`을 다시 만듭니다.

```json
{ "level": 1, "pattern": "I'm trying to ___", "ko": "~하려고 하는 중입니다",
  "tip": "멍개가 할 한마디. 데드팬으로 단정하고 끝냅니다.",
  "ex": [["English sentence.", "한국어 뜻."], ["...", "..."]] }
```

빌드가 막아주는 것들입니다. 레벨 값 오류, 예문 3개 미만, 빈 문자열, 마스터 인덱스에 없는 패턴, 주입 자리 누락. 하나라도 걸리면 빌드가 멈추고 이유를 찍습니다.

## 변경 이력

사용자가 체감할 변화가 생기면 `CHANGELOG.md`의 `[미출시]`에 적습니다. 릴리즈할 때 워크플로우가 버전 번호를 붙여 아래로 내리고, 그 내용을 그대로 GitHub Release 노트로 씁니다. 데이터 버전을 올려놓고 이력을 안 적으면 빌드가 경고합니다.

## 습득 판정

자가채점으로는 마지막 한 칸을 못 넘습니다.

**처음 → 익히는 중 → 안정 → 내 것**

'내 것'은 검정을 통과해야만 붙습니다. 응시 조건은 서로 다른 예문 3개에서 성공, 5초 이내 즉답 2회 연속, 복습 간격 7일 이상 생존. 검정은 훈련에 한 번도 쓰지 않은 봉인 예문으로 봅니다. 통과 후에도 35일 뒤 유지 검정이 돌아오고, 실패하면 배지를 회수합니다.
