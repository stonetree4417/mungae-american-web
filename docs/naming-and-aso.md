# 멍개미국어 — 이름은 지키고 검색은 따로 먹는 법

## 결론

이름을 바꾸지 마십시오. **'미국어'는 브랜드로 쓰고, '영어'는 검색어로 씁니다.** 둘은 싸우는 관계가 아니라 층이 다른 문제입니다. 사람들은 '영어 패턴'으로 찾아 들어와서 '멍개미국어'로 기억하고 나가면 됩니다. 그게 브랜드가 만들어지는 순서입니다.

'미국어'를 포기하면 안 되는 이유는 단순합니다. 검색은 돈으로도 사지만, **한 번 듣고 기억에 남는 이름은 돈으로 못 삽니다.** 영어 학습 앱 중에 이름으로 기억되는 게 몇 개입니까.

---

## 1. 플레이스토어

제목은 30자 제한입니다. 브랜드 뒤에 키워드를 붙입니다.

| 항목 | 내용 |
|---|---|
| 앱 이름 (30자) | `멍개미국어 : 영어회화 패턴 60` |
| 짧은 설명 (80자) | `학교에서 배운 문법은 충분합니다. 미국인이 실제로 쓰는 영어회화 패턴 60개를 검정으로 확인하며 익힙니다.` |
| 개발자명 | `JNP Solution` |

긴 설명은 **첫 3줄**이 검색 인덱싱에서 가장 무겁습니다. 여기에 키워드를 자연스럽게 깔고, 브랜드 서사는 그 아래로 내립니다.

> 영어회화가 안 되는 건 문법을 몰라서가 아닙니다. 실전에서 쓰는 **영어 패턴**이 입에 없기 때문입니다.
> 멍개미국어는 미국 현지에서 실제로 통하는 패턴 60개를 예문 300개로 익히고, 검정으로 습득 여부를 확인하는 **영어회화 학습 앱**입니다.
> 비즈니스 영어, 해외 출장, 미국 여행에서 바로 쓰는 표현만 담았습니다.

노려야 할 키워드는 이렇습니다. 영어회화 / 영어 패턴 / 영어회화 패턴 / 비즈니스 영어 / 영어 말하기 / 여행 영어. 반대로 **'미국어'는 아무도 검색하지 않으니 키워드 칸에 넣지 마십시오.** 대신 브랜드 검색어로 자라기를 기다리면 됩니다.

## 2. 웹과 블로그

- 랜딩은 `mungae.co/american`. 페이지 `<title>`은 `멍개미국어 — 영어회화 패턴 60`, `<h1>`은 `영어 아니고 미국어`로 갈라 둡니다. 검색엔진은 title을 읽고, 사람은 h1을 봅니다.
- 블로그 유입 글은 **'영어 패턴'** 검색어로 씁니다. 「미국인이 하루에 열 번 쓰는 영어 패턴 10개」 같은 제목으로 들어와서, 본문 안에서 "우리가 배우는 건 영어가 아니라 미국어입니다" 한 줄로 브랜드를 심습니다. 농담은 설명하지 않습니다.
- 검색량이 없다는 건 **경쟁자도 없다는 뜻**입니다. '미국어'로 검색했을 때 1위가 되는 건 지금 바로 가능합니다. 브랜드가 알려진 뒤에 그 자리를 남이 차지하고 있으면 곤란해집니다. 선점만 해두십시오.

## 3. 유튜브·샤오홍슈

숏폼 제목은 검색이 아니라 후킹입니다. 여기서는 '미국어'가 오히려 무기입니다.

> "영어 말고 미국어. 미국 애들은 이렇게 말합니다."

같은 영상의 설명란과 해시태그에는 `#영어회화 #영어패턴 #비즈니스영어`를 답니다. 화면에는 미국어, 메타데이터에는 영어. 이 원칙 하나로 전 채널을 운영하시면 됩니다.

## 4. 멍개 브랜드 안에서의 자리

| | 멍개중국어 | 멍개미국어 |
|---|---|---|
| 한자 | 孟狗中国语 | 孟狗美语 |
| 검색 기둥 | HSK, 중국어 단어 | 영어회화, 영어 패턴 |
| 학습 단위 | 어휘 → 문법 | 패턴 → 어휘 |
| 서사 | 멍개의 중국 활동 | 멍개의 미국 진출 |

차이나타운 출신 래퍼가 중국어와 미국어를 둘 다 하는 건 설명이 필요 없는 설정입니다. 나중에 언어가 더 붙어도 이 구조는 그대로 버팁니다.
